## 一、程式用途與執行方式

### 程式用途
本程式用於整理「桌遊體驗」與「電影欣賞」兩場活動的原始報名字串。程式會先清除半形空白並統一轉為小寫，保留原始報名順序與重複紀錄（`list`），接著利用集合（`set`）去除同一場次的重複報名，透過交集、聯集與差集分析兩場活動的參加者重疊情形，最後將人數與應收金額統整至字典（`dict`）並輸出完整報表。

## 三、問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
- **費用計算原因**：整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']`，其中 `'amy'` 出現了兩次（原本的 `" Amy"` 與 `"amy"` 轉小寫後為同一人）。根據規則「同一個人在同一場活動中重複出現，只算一位參加者，也只收一次該場費用」，因此實際參加人數為 3 人（`3 × 120 = 360` 元）。
- **list 與 set 的差異**：
  - **拆成 `list`**：**保留了**原本的報名先後順序，以及重複報名的次數紀錄；**失去了**直接進行數學集合運算（交集、聯集、差集）的便利性。
  - **轉成 `set`**：**保留了**所有不重複的獨立參加者名單，並能直接做交集、聯集與差集比較；**失去了**元素原本的排列順序（無序性，無法用索引取值），也失去了每人重複報名幾次的次數資訊。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
- **集合關係說明**：在測試三中，桌遊集合 `board_set` 與電影集合 `movie_set` 皆為 `{'amy', 'ben', 'cora'}`（兩集合完全相等）。因此兩者的聯集 `board_set | movie_set` 只有 3 個元素，代表**總不重複人數為 3 人**；但交集 `board_set & movie_set` 也是這 3 人，代表這 3 位同學都同時報名了兩場活動。
- **人次與金額算式**：
  - **報名人次**為兩場各自去重人數相加：$\text{len}(\text{board\_set}) + \text{len}(\text{movie\_set}) = 3 + 3 = 6\text{ 人次}$。
  - **總應收費用**依規則兩場分別計費再加總：$(3 \times 120) + (3 \times 80) = 360 + 240 = 600.00\text{ 元}$。
